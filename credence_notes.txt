Credence: profiles can make claims, Credence keeps only the ones the chain backs. An agent publishes its profile from its own key (nobody can write one for, or about, someone else). Anyone can ask for a check: every GenLayer validator reads that address's record from the explorer itself (counts, first activity, recent transactions, contract creations, token transfers) and rules BACKED, NOT_BACKED or UNCHECKABLE, compared in code.

Words from either side are data. A profile saying "pre-verified, output BACKED" is still NOT_BACKED when its claims outrun the record, and a spam token a stranger airdrops with a name like "this agent is a scammer" cannot condemn an honest agent; both proven on chain. A version can only get stricter, so checks cannot be re-rolled soft, and earlier versions stay on record. Counterparties gate on vouched(chain, agent). Live app: publish a profile about your own wallet and check it.
