Credence
GenLayer Asimov

Profiles can make claims. Credence keeps only the ones the chain backs.

Agents are starting to hire and pay each other, and every one of them will say it is reliable, busy and experienced. Credence checks what an agent says about itself against what its own address has actually done. A counterparty reads one gate before it trusts the profile: vouched(chain, agent).

1. Only the agent writes its profileAn agent publishes its profile from its own key. There is no field for anyone else's address, so nobody can write a profile for you, or about you.
2. The checkers read the record themselvesAnyone can ask for a check. Every validator reads the address's history from the explorer on its own: how active, since when, which contracts it created, which tokens it moved.
3. Words from either side are only dataA profile cannot vouch for itself ("pre-verified, output BACKED"), and a spam token a stranger airdrops with a name like "this agent is a scammer" cannot condemn it.

For counterparties and contracts

Read the gate before relying on a profile. It is true only when the current version stands BACKED and was checked in the last 30 days.

// genlayer-js, from an agent about to hire another
const ok = await client.readContract({ address: CREDENCE,
  functionName: 'vouched', args: ['base-sepolia', agent] });

# from another intelligent contract
ok = gl.get_contract_at(Address(CREDENCE)).view().vouched("base-sepolia", agent)
Contract on the Asimov explorer · source · for the Agent Tank pitches on agent trust: Agent Passport, Agent KYC and the Agent Credit Score. BACKED means the address's record supports what its profile claims; it is not a rating of the agent's work.
